# Razorpay Setup Guide (RESTORED)

## 1. Create Account
- Go to [Razorpay](https://razorpay.com/) and create an account.
- Navigate to **Settings** -> **API Keys**.

## 2. Generate Keys
- Generate "Test Mode" keys.
- Copy your **Key ID** and **Key Secret**.

## 3. Configure App
- Add these keys to your `.env` file in the `backend/` folder.
